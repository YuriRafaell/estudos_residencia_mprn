## 📝 Resumo de Véspera para fixar na memória (Garante Questões):

* 
* Portas: HTTP usa a porta 80. HTTPS (criptografado) usa a porta 443. [4, 5, 6] 
* Verbos: GET (buscar dados), POST (enviar/criar dado novo), PUT (atualizar dado existente), DELETE (deletar dado). [7, 8] 
* Status Favoritos das Bancas:
* 200 (OK - Sucesso)
   * 201 (Created - Objeto criado com sucesso no POST)
   * 400 (Bad Request - Requisição errada enviada pelo cliente)
   * 404 (Not Found - URL ou recurso não encontrado)
   * 500 (Internal Server Error - O servidor quebrou) [9, 10, 11, 12] 
* Formatos: JSON usa chaves e colchetes { "chave": "valor" }. XML usa tags parecidas com HTML <tag>valor</tag>. CSV usa linhas simples separadas por vírgula ou ponto e vírgula. [13, 14, 15, 16, 17]
