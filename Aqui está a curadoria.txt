⏱️ BLOCO 1: REST API vs. SOAP (Total: 50 minutos)
Você precisa entender os conceitos arquiteturais e as diferenças estruturais entre as duas tecnologias.

- Vídeo 1 (REST vs SOAP - Teoria Direta) - 00 a 20 min: Assista ao Web Services: SOAP vs REST // Dicionário do Programador do Código Fonte TV. Eles explicam perfeitamente a diferença conceitual: o SOAP como um protocolo rígido baseado em contratos (WSDL) e XML, e o REST como um estilo arquitetural flexível baseado em HTTP e URIs (endpoints).

- Vídeo 2 (Endpoints, Requisições e Respostas) - 20 a 50 min: Assista ao O que é uma API REST / RESTful? do canal Otavio Lemos. Ele demonstra na prática o que é um endpoint (a URL que você acessa), como funciona a estrutura de uma requisição (Headers e Body) e como o servidor devolve a resposta.
